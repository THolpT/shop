# Запуск приложения

## Требования

Перед запуском приложения убедитесь, что установлены:

* **Node.js**
* **.NET SDK 9.0**


---

## Запуск клиентской части

Перейдите в папку `client`:

```bash
cd client
```

Установите зависимости:

```bash
npm i
```

Запустите приложение в режиме разработки:

```bash
npm run dev
```

После запуска клиент будет доступен по адресу, который будет указан в консоли(localhost:3000 по умолчанию).

---

## Запуск серверной части

Откройте **новый терминал** и перейдите в папку сервера:

```bash
cd server/server
```

Запустите сервер:

```bash
dotnet run
```
